# 🍿 Cine1000DEVs — Cineminha MilDevs

Um projeto desenvolvido durante o **Bootcamp 1000Devs**, com o objetivo de criar uma página web de apresentação de filmes, utilizando conceitos fundamentais de desenvolvimento Front-End.

## 🎬 Sobre o projeto

O Cine1000DEVs é um catálogo de filmes que permite aos visitantes visualizar títulos em cartaz e acessar páginas individuais com informações sobre cada produção.

O projeto foi desenvolvido como uma atividade prática de aprendizado, aplicando conceitos de estruturação de páginas, organização de conteúdo e estilização com CSS.

## ✨ Funcionalidades

- Exibição de filmes em formato de catálogo.
- Apresentação dos pôsteres dos filmes.
- Informações sobre gênero e duração.
- Navegação entre a página inicial e as páginas individuais dos filmes.
- Visualização de sinopses e detalhes das produções.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização e apresentação visual das páginas.
- **CSS Flexbox:** organização dos elementos do cabeçalho.
- **CSS Grid:** organização dos cartões de filmes em grade.
